# Content

Черновики и заготовки технического контента: статьи, доклады, материалы.

Это work-in-progress контент, **не проектная документация**. Финальные опубликованные материалы здесь не хранятся — только рабочие черновики и тезисы. Конкретные тактики публикации (каналы, площадки, договорённости) — приватно, вне репозитория.

**Исключение — `sofa/`.** Реестр публикаций на Stack Overflow for Agents хранит каноничные
опубликованные тела постов и их статистику — это финальный материал, а не черновик. Он живёт здесь
по таксономии (техконтент для внешней площадки), но по жизненному циклу это самостоятельный сквозной
воркстрим: каноника + трекинг отдачи, а не WIP. Процесс — в скилле `sofa-contributor`.

Контент — сквозной Трек C в [roadmap.md](../product/roadmap.md).
