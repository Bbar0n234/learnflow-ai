# LearnFlowAI — Идея

## Проблема

Tech-спикеры и докладчики — разработчики, архитекторы, тимлиды — регулярно готовят материалы для выступлений, статей, курсов. У них есть экспертиза и контекст по теме, но систематизация этого контекста в готовый материал — рутина, которая съедает часы.

Существующие LLM-инструменты не решают эту задачу:

- **Контекст между сессиями теряется.** ChatGPT Projects, память — работают поверхностно. Новый чат видит ключевые слова, но не глубину проработки. Каждый раз приходится заново объяснять контекст.
- **Качество research слабое для нишевых тем.** Темы докладов часто за пределами обучающей выборки LLM. Встроенный поиск ChatGPT работает плохо, Perplexity ищет лучше, но неудобна для остального workflow.
- **Презентации делаются руками.** 75% докладов = презентация. В текущих инструментах слайды приходится собирать вручную.

Все существующие решения — generic. Ни одно не заточено под подготовку образовательных и технических материалов.

## Целевая аудитория (ICP)

**Первичная:** tech-спикеры и докладчики — разработчики, архитекторы, тимлиды, которые готовят материалы для выступлений, статей, курсов.

Характеристики:
- Имеют экспертизу в теме
- Много мыслей и контекста, но нет времени на систематизацию
- Ценят структуру и качество подачи

**Расширение (v2+):** самоучки, которые структурируют знания для себя. Общая техническая база, другие выходные артефакты.

## Решение

LearnFlowAI — AI-инструмент, который превращает мысли и контекст эксперта в структурированные материалы для докладов, статей и курсов.

В основе — **проект как "шар контекста"**: пользователь создаёт проект (лекция, курс, доклад), внутри которого ведутся чаты, накапливаются артефакты и выстраивается связанная картина. Контекст не теряется между сессиями — агент помнит, что обсуждалось, какие решения приняты, какие материалы уже есть. При этом контекст не засоряется: агент подгружает только то, что нужно для текущей задачи.

## Конкурентное преимущество

1. **Специализация** — не generic LLM, а инструмент для подготовки материалов. Все решения оптимизированы под этот сценарий.
2. **General Agent + Skills** — гибкий агент с подгружаемыми навыками методистов. Skills = знания от людей (как структурировать, какие паттерны использовать). Пополняются автором и контрибьюторами, дают персонализацию стиля.
3. **Шар контекста** — умное управление контекстом между сессиями. Связанная картина проекта вместо атомарных фактов. Progressive disclosure: агент получает минимальный контекст и углубляется по требованию.
4. **Open-source (Apache 2.0)** — кастомизация, self-host, возможность контрибьюции.

## Границы продукта

**Фильтр для фич:**
> Помогает ли это tech-спикерам (или самоучкам в v2+) готовить материалы? Если нет — фича не нужна, даже если "было бы круто".

**Что НЕ является целью:**
- Универсальный AI-ассистент на все случаи
- "Вау-демо" без реальной ценности
- Идеальный код ради идеального кода
