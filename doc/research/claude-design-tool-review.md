# Claude Design — обзор инструмента по итогам реальной сессии

Дата: 2026-06-12. Контекст: концепт-сессия брендинга LearnFlowAI (итерация feat-007, см. [бриф](../tasks/iterations/frontend/feat-007-design-branding/reference-brand-brief.md) и [handoff bundle](../tasks/iterations/frontend/feat-007-design-branding/design-handoff/)). Инструмент — [Claude Design](https://claude.ai/design) от Anthropic Labs (research preview, доступен с Pro), powered by Opus 4.7.

## Ожидание vs реальность

Ожидание было «вкладка в чате: та же модель плюс пара дизайн-инструментов в промпте». Реальность — отдельная платформа со своей иерархией:

```
Организация
├── Design Systems (N штук; «Published» → применяется ко всем новым проектам)
└── Projects: Prototype (wireframe | high fidelity) / Slide deck / Other
      каждый = чат + canvas, версии, шеринг (view/comment/edit), экспорт
```

## Что показала сессия

- **Обвязка — главная ценность.** Инструмент структурированно ведёт работу: характер интерфейса, палитра, типографика подаются как осязаемые артефакты, варианты сравниваются на canvas. На «голом» агенте всё это пришлось бы промптить и организовывать вручную.
- **Модель сильна в дизайне.** Уровень «накидал идеи — получил осмысленно разложенные направления». Концепт-направления с первого захода пригодны для выбора.
- **Удобный ввод контекста.** Файлы любых форматов (markdown-бриф, jpg-референсы), линк кодовой базы, web capture. Контекст реально вычитывается и влияет на результат.
- **Lock-in смягчён экспортом.** Обычный минус такой обвязки — привязка к провайдеру и трудная миграция. Здесь экспорт — заявленный приоритет: ZIP / PDF / PPTX / Canva / standalone HTML / **handoff bundle для Claude Code**. Наработки переносимы.
- **Handoff bundle впечатляет полнотой.** На выходе сессии — пакет: README-спецификация (дизайн-токены в hex+OKLch с маппингом на наши CSS-переменные, типографика, экраны с размерами, interactions, state management, статус ассетов) + dc.html-прототипы экранов. Это фактически готовый вход для реализационной итерации агентом.

## Вердикт

Для не-дизайнера — must-have: способ получить дизайн уровня «не стыдно показать», не будучи дизайнером. Качество и скорость выше, чем у ванильного агента, lock-in-риск низкий из-за экспорта. Связка «Claude Code (бриф, материалы) → Claude Design (концепты, спека) → Claude Code (реализация)» отработала без зазоров.

Паттерн design system на будущее: после фиксации бренда залить его как опубликованную Design System организации — тогда любые последующие проекты (презентации, лендинги, баннеры — Трек C) генерятся в бренде автоматически. Для заливки из кода есть инструмент DesignSync в Claude Code.

## Не протестировано

Inline-комментарии на элементах canvas, прямое ручное редактирование, custom-слайдеры, мобильные макеты, флоу «Set up design system» (онбординг организации), web capture. Known issues (по докам): пропадающие inline-комменты (workaround — дублировать в чат), лаги на больших репозиториях (линковать поддиректорию).
