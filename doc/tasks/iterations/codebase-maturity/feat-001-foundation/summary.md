# feat-001 Foundation — Post-Implementation Summary

Итерация выполнена полностью, DoD закрыт. Verification по чек-листу не требовалась — итерация документационная (код не менялся), приёмка — ревью архитектора по каждому артефакту в диалоге.

## Что сделано

**Part A — Skill Discovery (расширился против исходного скоупа):**
- Двухволновое дискавери: разбор установленных скиллов + целевая внешняя охота по каталогам (исходный скоуп предполагал только web search). Каждый скилл разобран с архитектором по ритму «пересказ → видение → решение»; рабочий трекер — `skill-discovery-draft.md` (заморожен как исторический артефакт).
- Решения: 5 внешних принято (`api-design-principles`, `postgresql`, `fastapi`, `feature-sliced-design`, `frontend-design` с трёхфазной режимной политикой), 3 авторских как есть, 2 отклонено (`langchain-architecture` — удалён в т.ч. глобально; `react-state-management` — ядро переиспользуется конвенцией в frontend-slice).
- Финализация: постоянная карта `doc/tech/skill-map.md` (4 мета-принципа + 2 операционных правила + политики + пробелы + отложенные кандидаты), таблица скиллов в CLAUDE.md дополнена, принятые скиллы версионируются в `.claude/skills/`.

**Part B — Диаграммы (расширился с «одной диаграммы» до восьми):**
- Принцип размещения: карта сервисов — в `vision.md`, слои сервиса — в документе сервиса (отдельный layers.md отклонён архитектором).
- `vision.md` — общесистемная карта актуализирована (добавлен SIEM-контур, Redis Streams, siem-contracts; диаграмма была до-SIEM-ной).
- `backend.md` — детальная послойная (внешние системы, связи верифицированы grep'ом и сабагентом), сквозной chat-поток, карта persistence (LangGraph-managed vs app-managed).
- `frontend.md` — послойная as-is + поток данных по осям состояния (первые Mermaid в документе).
- `doc/tech/siem-service.md` — **новый архитектурный документ** (топология, послойная с границей сервиса, event pipeline, correlation engine + lifecycle алерта, persistence, REST API, конфигурация); секция SIEM в backend.md сжата до ссылки. Материал: ADR-018..021, design-brief feat-005-security-event-pipeline, код сервиса.

## Решения и паттерны, родившиеся в итерации

- **Паттерн диаграмм** (зафиксирован в conventions.md § Mermaid Styling): слои — subgraph-подложки с полупрозрачной заливкой и цветным stroke/заголовком, палитра проекта, верификация связей по коду (grep/сабагент), проверка рендера на тёмной теме. Запрет `fill:` на нодах сохранён.
- **Правило CLAUDE.md «без временных метапометок»**: документация описывает текущее состояние, ссылки на итерации не оставляются (вычищено 4 примера).
- **Правило CLAUDE.md «fix drift on sight»**: замеченные по пути некорректности исправляются в рамках задачи при 100% уверенности (верификация по коду / эскалация архитектору).
