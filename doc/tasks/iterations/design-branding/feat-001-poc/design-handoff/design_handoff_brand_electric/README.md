# Handoff: брендинг LearnFlowAI — направление «Чернила / Электрик»

Итерация feat-007 (design-branding). Пакет — вход реализационной итерации для Claude Code.

## Overview

Переработка визуальной идентичности LearnFlowAI с дефолтного shadcn на фирменную систему «Чернила / Электрик»: тёплая бумажная основа + один плоский фиолетовый акцент, serif-акценты в заголовках, сфера знаний как визуальное ядро бренда. Покрыты: токены light+dark, wordmark и знак, главный рабочий экран (чат + три панели), Сфера знаний, Welcome, Артефакты, плюс поведенческие паттерны (студия-панель, peek в ленте, оверлей-линза, семвер-версии сферы).

Характер бренда: спокойный · умный · тёплый · собранный. Идея серии: «учёба — это интересно, активно и эффективно». Анти-цели: детскость, корпоративный холод, generic-AI-эстетика (фиолетовые ГРАДИЕНТЫ в UI запрещены — фиолетовый здесь всегда плоский, градиент живёт только внутри сферы-орба).

## About the Design Files

Файлы `*.dc.html` в этом пакете — **дизайн-референсы, созданные в HTML** (Claude Design). Это прототипы, показывающие целевой вид и поведение, а НЕ production-код. Задача — **воссоздать эти макеты в существующем фронтенде проекта**: React + TypeScript, Tailwind CSS v4 (`@theme` в `frontend/src/index.css`, без config-файла), shadcn/ui (base-nova), иконки lucide. Не копировать HTML напрямую; перенести токены в CSS-переменные и реализовать экраны существующими компонентами/паттернами кодовой базы.

Каждый dc.html — страница-презентация: серый фон, на нём белые карточки с макетами 1352×832 (полные экраны приложения) и пояснениями. Открываются в браузере (рядом должен лежать `support.js`).

## Fidelity

**High-fidelity.** Цвета, типографика, отступы, радиусы и копирайт в макетах — финальные. Воспроизводить пиксельно, но средствами существующей дизайн-системы (CVA-варианты, tailwind-токены). Числа в макетах дизайн-масштаба 1352px-ширины; при реализации использовать как точные значения (это десктоп ~1440 с учётом рамки).

### Сфера-орб (единственное место с градиентом)

- Light: `radial-gradient(circle at 38% 32%, #A47CFA 0%, #7434F4 52%, #4C16B8 100%)`, тень `0 6px 26px rgba(116,52,244,0.35)`.
- Dark: `radial-gradient(circle at 38% 32%, #D0BAFF 0%, #9D6FFF 50%, #5520C8 100%)`, свечение `0 0 44–48px rgba(177,148,255,0.45–0.5)`.
- Вокруг большого орба — 2 концентрических кольца: light `#E5DCFC` / `#CDB9F8`, dark `rgba(177,148,255,0.25/0.45)`.
- Искры — ромбы (квадрат, `rotate(45deg)`) 5–11px, цвета: сирень/акцент/крем. 2–3 штуки максимум, только возле сферы и врезок.

### Радиусы, типографика, прочее

- Радиусы: кнопки 9–11px; карточки 11–14px; макет/модал 14–18px; чипы `999px`. Базовый `--radius: 0.7rem`.
- Шрифты (заменяют Geist Variable):
  - **Source Serif 4** 600/700 — заголовки, имена сущностей (проекты, артефакты, «Сфера знаний»), H-уровни в markdown.
  - **Instrument Sans** 400/500/600/700 — весь UI и body-текст.
  - **IBM Plex Mono** 400/500 — версии (`2.4.1`), таймкоды, тех-метки врезок. Не для body.
- Кегли (дизайн-масштаб): H1 экрана 22–26px serif; заголовок чата 17px serif; body 14–14.5px; вторичный 12–12.5px; метки-капс 11px, letter-spacing 0.09em; mono-метки 10.5–12px.
- Тени почти не используются: только инпут-бар (`0 2px 10px rgba(80,70,50,0.06)`), модал линзы (`0 24px 80px rgba(24,16,36,0.35)`) и свечение орба в dark.
- Эмодзи в UI не используются. Иконки — lucide, в тон текста.

## Interactions & Behavior

- **Семвер сферы**: каждое сохранение — версия `major.minor.patch`. Агент предлагает уровень по размеру правки (патч — правки внутри записей; минор — новые записи/раздел; мажор — реструктуризация/смена тезисов); человек подтверждает в дропдауне «Сохранить версию ▾» (предложение агента предвыбрано и подсвечено лавандой). Бейджи версий: мажор — заливка primary, минор/патч — лаванда.
- **Доступ к сфере из чата**: основной жест — студия-панель S1.2 (открывается чипом в ChatHeader, переключатель Сфера|Артефакты, состояние сохраняется на чат); дополняющие — линза S2 (быстрый просмотр, Esc) и peek S3 (автоматически при записи агента в сферу, сворачиваемый, с откатом).
- Tool-call'ы агента — чипы на лаванде с точкой-маркером; стриминг — индикатор-прямоугольник + текст текущего действия.
- Hover: пункты списков — фон `--muted`; кнопки primary — затемнение ~6%; карточки списка артефактов — бордер темнеет.
- Переходы: панели/модалы 150–200ms ease-out; без декоративных анимаций. Позиция в чате и открытость студии — персистентны.

## State Management

- `theme: light|dark` (класс `.dark`).
- `studioPanel: { open: boolean, tab: 'sphere'|'artifacts', selectedArtifactId }` — на уровне чата.
