# Кандидаты прозрачного PNG

Каталог содержит два равноправных candidate-пака для архитектурного ревью.
Исходные изображения в `final/light/` и `final/dark/` не изменялись.

## Профили

### `soft-balanced`

- RGB-distance: `8/28`;
- более консервативная граница;
- лучше страхует очень светлые края страниц, одежды, бороды и печи;
- может оставить немного больше исходной кремовой примеси в edge RGB.

### `soft-wide`

- RGB-distance: `12/42`;
- шире переходная alpha-зона и сильнее удаление фоновых пикселей;
- визуально чище вокруг дымок, искр и внешнего воздуха сцены;
- потенциально сильнее истончает светлые края.

Оба алгоритма удаляют только области, связанные с границей изображения.
Внутренние страницы, блики и другие светлые элементы не становятся прозрачными
только из-за сходства с цветом фона.

## Структура

```text
transparent/
├── soft-balanced/
│   ├── light/  # 6 PNG
│   └── dark/   # 6 PNG
├── soft-wide/
│   ├── light/  # 6 PNG
│   └── dark/   # 6 PNG
├── contact-sheet-*.jpg
└── manifest.json
```

Contact sheets построены на белом, кремовом, чёрном и UI dark `#181420` фоне
отдельно для light- и dark-пака. `manifest.json` фиксирует пороги, оценённый цвет
фона, доли прозрачных пикселей, размеры и время каждого из 24 запусков.

## Статус

Оба профиля ожидают аппрува архитектора. До выбора:

- файлы не копируются в production/final-каталог;
- SVG-векторизация не запускается;
- остальные методы остаются только историей benchmark в
  `experiments/09-background-removal/`.

Воспроизведение:

```bash
/tmp/lf-bg-benchmark-venv/bin/python \
  refs/illustrations/experiments/09-background-removal/tools/build_candidates.py
```
