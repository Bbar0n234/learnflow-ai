# Test Cases: feat-004 — Design-system integration

## Природа итерации и стратегия проверки

Это визуальный редизайн + релейаут. Бóльшая часть приёмки — **визуальная сверка с хэндоффом на живых экранах**, что в автономном/облачном прогоне недостижимо. Поэтому:

- **Layer 0 (automated gate)** — прогоняется на каждом треке, блокирующий: `make check-fe` (ESLint + Prettier) и `tsc -b && vite build` зелёные.
- **👤 (manual UI)** — визуальные кейсы tester помечает как требующие ручной проверки и **эскалирует архитектору** (локальная приёмка после merge). В облаке не закрываются автоматически.
- **Функциональные кейсы** (тема, заглушки, отсутствие краша) — проверяются прогоном/скриптово, где возможно.
