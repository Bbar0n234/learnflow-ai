# feat-006 — Пере-свап ассетов на production cutout: summary

## Результат

Все 12 иллюстраций во frontend (`frontend/src/shared/assets/illustrations/{light,dark}/`)
заменены с PoC-версий локального cutout на production-пак feat-002
(BiRefNet General-HR + ручная дочистка). Живой просмотр архитектором пройден
на реальных экранах в обеих темах: welcome, sidebar, empty-состояния
(chats / sphere / artifacts), error-state. Итерация принята.

Свап оказался тривиальным, как и задумывалось в feat-004: имена сцен и размеры
холстов совпадают 1:1, компоненты ходят к ассетам только через централизованную
карту `getIllustration()` — правки кода не потребовалось вовсе, только замена
файлов. Новые PNG легче старых на ~35–50 % (чистая альфа лучше сжимается).

## Единственная правка по результатам живого просмотра: sidebar-vignette

На живом просмотре обнаружилось: светлый и тёмный арты sidebar-vignette
нарисованы в разном масштабе (контент светлой занимает 1609×482 на холсте
1983×793, тёмной — 1750×537), из-за чего при переключении темы кот заметно
менял размер и позицию. В старом паке это маскировалось мусорными полями
тёмного локального cutout.

Фикс — регистрация светлого арта под тёмный по максимуму IoU альфа-масок
(сцены — одна композиция, тёмная является перекраской):

- масштаб **1.095**, offset **(116, 148)**, итоговый IoU масок **0.90**;
- один ресемплинг LANCZOS от исходника пака (без двойной потери качества);
- воспроизведение: `tools/register_vignette.py`.

Остаточные расхождения (угол пера, форма дымков) — различия самих рисунков
(тёмная сцена — генеративная адаптация), трансформацией не устраняются и при
переключении темы читаются как перерисовка, а не перескок. Принято архитектором.

**Следствие:** `light/sidebar-vignette.png` во frontend — не байт-в-байт с
паком feat-002, а его аффинная адаптация. При будущем пере-свапе из пака не
потерять: прогнать `tools/register_vignette.py` после копирования файлов.
Остальные 11 файлов байт-идентичны паку.

## Использование ассетов

Каждая сцена используется ровно в одном месте, прямых импортов PNG мимо
централизованной карты нет:

| Сцена | Компонент |
|---|---|
| welcome-hero | `pages/welcome/ui/WelcomePage.tsx` |
| sidebar-vignette | `app/components/Sidebar.tsx` |
| empty-chats | `pages/project-chats/ui/ChatList.tsx` |
| empty-sphere | `pages/sphere/ui/SphereViewer.tsx` |
| empty-artifacts | `pages/artifacts/ui/ArtifactList.tsx` |
| error-state | `app/components/ErrorBoundary.tsx` |

## Границы итерации

- **Художественная перегенерация сцен не потребовалась** — по живому просмотру
  точечных претензий к артам не осталось (единственная правка — регистрация
  виньетки выше).
- **SVG-вопрос остаётся в feat-003 (⏸️).** Если когда-либо решится в пользу SVG
  для сцен — свап будет точечным благодаря той же централизованной карте
  (замена расширения/импорта в `shared/assets/illustrations/index.ts`).

## Артефакты

| Артефакт | Что это |
|---|---|
| `frontend/src/shared/assets/illustrations/{light,dark}/` | Production-ассеты в бою (12 PNG) |

| `../feat-002-cutout/cutouts/{light,dark}/` | Канонический источник пака (не изменялся) |
