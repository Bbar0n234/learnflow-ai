Лента активности v3: живость, вход/выход, большие данные

База — вариант C · две оси выбора: индикатор активности × разметка деталей · субагент получает длинный task и возвращает вердикт
Активность
Детали
Что смотреть. (1) Живость: активная строка всегда движется — переключай «Точки / Shimmer / Пульс»; до первого события в ленте живёт строка-пауза; у действия дольше пары секунд появляется счётчик времени. (2) Вход/выход: в развороте зоны вызова и результата различимы — «Метки / Стрелки / Фон» (оси независимы, комбинируй). (3) Большие данные: субагент получает task ~1.2k токенов и возвращает вердикт ~0.9k — обрезка в 3 строки с «Показать полностью», раскрытие в прокручиваемую зону. Разворачивай субагента и поиск кликом.
Контракт один для всех комбинаций: усечение и разметка — клиентские. Полные args/результат живут в typed parts сообщения; в стрим уходят усечёнными до лимита.
