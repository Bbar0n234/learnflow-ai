# Harvest Proposals — feat-002-chat-ux

Финализировано harvester'ом на фазе HARVEST. Консолидирует 9 anytime-записей оркестратора (сохранены все, ничего не потеряно) + новые кандидаты из `tracks/*/summary.md` Follow-ups, `review-a.md`/`review-b.md`, `tracks/*/test-cases.md`, дополнительных кандидатов от docs-updater.

## Отсеяно как шум (с причиной — для прозрачности гейта)

- **`LangGraphAgentRunner.delete_thread` no-op при `checkpointer is None`** (review-b pre-existing, `backend/app/agent/runner.py:366-377`) — сам ревьюер явно квалифицирует как «принятую цену тест-границы, не как дефект»: ветка существует только ради keyword-only параметра с дефолтом для тестовых конструкторов, наблюдаемость (`logger.warning`) соблюдена.
- **Ранний commit в `send_message` снял неявную сериализацию «нельзя удалить чат, пока он стримит» (FX8)** — осознанно принятое следствие фикса F1, зафиксировано в `tracks/T1/summary.md` как решение, а не как незакрытая находка; альтернатива («вернуть сериализацию») буквально возвращает баг F1.
- **Восемь находок CODE_REVIEW (FX1–FX8: teardown фоновых задач, `CancelledError`, атомарный pre-write guard, docstring-инварианты, `rename_chat` commit, `delete_chat` fail-fast, `assert`→narrowing)** — все закрыты фиксером в рамках итерации, дублирующей записи нет.
- **Все `[test]`-находки TEST_REVIEW обоих треков (T1: R1–R9 кроме R5/R6; T2: R1–R11)** — закрыты test-author'ом в цикле GREEN, задокументированы построчно в соответствующих `test-cases.md`; хвостов не оставляют.
- **Осознанно не чинённые находки review-a/review-b, явно поставленные архитектору как решения без нового кода** (whitespace-only title, `ProjectCreate.name`, `aria-label`, `collisionPadding`) заведены выше в backlog — здесь не дублируются повторно как шум.
