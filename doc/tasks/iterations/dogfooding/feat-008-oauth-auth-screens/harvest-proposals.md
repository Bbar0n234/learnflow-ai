# Harvest proposals — feat-008

Финализируется ролью `harvester` на фазе HARVEST. До того — anytime-записи оркестратора.

## Anytime-записи оркестратора

- **[doc] Drift прод-топологии в design-brief feat-008** (находка ревью партиции #9): диаграмма топологий рисует прод как «nginx → SPA-статика · /api → backend», фактически образ `app` сам собирает фронт (`backend/Dockerfile`, стадия `frontend-build`) и отдаёт SPA из `main.py` (`StaticFiles` + catch-all `serve_frontend`). Для итерации это безвредно (маршрут `/login` и редирект `/{next}` переживают прямой заход без правок), но при DOC_UPDATE проверить, не унаследует ли `auth.md` эту неточность; сам бриф — read-only история, не актуализируется.
- **[infra/worktree] `.env.local` этого worktree не переопределяет `REDIS_URL` на localhost** — `make dev` доходит до `Application startup complete`, но с нефатальной Redis DNS-ошибкой (hostname docker-сети). Обнаружено implementer'ом T1.2. Учесть при ручных прогонах INTEGRATION_TEST; кандидат known-trivial (специфика конкретного worktree, не кода).
- **[Backend/auth] Multi-tab холодный старт vs replay-детекция refresh** (вопрос reviewer-A): бутстрап шлёт `POST /auth/refresh` при каждом холодном старте, а replay-детект гасит всю цепочку — две одновременно открытые вкладки с пустым localStorage разлогинивают пользователя везде. Класс pre-existing (раньше требовал 401 на рабочем запросе), частота выросла с бутстрапом. Кандидат в backlog (Backend, вместе с известным «single-worker» допущением).
- **[Observability] Гео-gate молча наследует `CLIENT_IP_SOURCE=socket` за прокси** (вопрос reviewer-A): все клиенты становятся RU (fail-closed, брифом принято как приемлемый misconfig), но ни одного сигнала в логе. Кандидат nice-to-have: warning на старте при `GEOIP_DB_PATH` заданном и `CLIENT_IP_SOURCE=socket`.
- **[UX/Backend] Локализация detail-строк парольного auth** (решение архитектора на INTEGRATION_TEST: backlog): «Invalid credentials», «Username already exists» и соседние строки `routes/auth.py`/`services/exceptions.py` показываются на русской странице `/login` по-английски (фронт по контракту рендерит `detail` сервера). Введены в первичной JWT-итерации (`f428c2d`), feat-008 не трогал; локализация тронет ассерты tests/auth и tests/oauth — отдельная малая итерация.
- **[security, приоритетно — частично закрыто в итерации] Pre-existing утечка секретов в лог при недоступном Redis**: необработанное исключение из `app/infra/redis.py::create_redis` печатает rich-traceback с `locals()`, включая все значения `Settings` открытым текстом (`jwt_secret`, `llm_api_key`, шесть OAuth-кредов). Обнаружено implementer'ом T1.8 при ручном прогоне (значения в артефакты не попали, временные логи удалены). Вне scope итерации; кандидат в backlog (Security/Backend): найти источник rich-traceback c show_locals (вероятно, глобальный `rich.traceback.install`) и/или барьер вокруг `create_redis` с `logger.warning` без locals. **Обновление:** класс утечки закрыт в итерации точечной митигацией (`RichTracebackFormatter(show_locals=False)`, коммит `4bb1fa2`) по решению архитектора; остаточный кандидат в backlog — SecretStr для секретных полей `Settings` (глубокая защита, см. Follow-ups T1).
- **[infra/worktree] Порт 8000 занят docker-контейнером соседнего worktree** (параллельная итерация): implementer T1.6 гонял ручные проверки на запасном порту, чужой контейнер не трогал. Учесть на INTEGRATION_TEST (dev-порт), известная особенность параллельной разработки, не аномалия.
- **[test-infra] Реальный список флейк-файлов `make test-fe` под нагрузкой шире известного**: помимо `SecurityRules`/`SecurityRouteGuard`/`MCPServersSection`/`CustomInstructionsSection` таймауты 5000 ms ловят также `SecurityEvents.test.tsx` и `SphereView.test.tsx` (в изоляции зелёные). Наблюдение tester'а T2. Кандидат в backlog вместе с флейком ниже (одна тема: устойчивость фронтовой сьюты под параллельной нагрузкой).
