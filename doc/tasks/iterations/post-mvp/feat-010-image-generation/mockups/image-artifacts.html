Аннотации к дизайну

1 Превью в карточке — решение принято. Карточка image-артефакта всегда с миниатюрой (64×40, скруглённая, с бордером) на месте типовой иконки; остальная вёрстка ArtifactCard не трогается. Превью в карточке — уменьшенное отображение того же изображения (тот же media-endpoint), отдельного thumbnail-эндпоинта в v1 нет.
2 Плейсхолдер на время генерации (10–30 сек). Рисуется по существующему SSE-событию tool_start (tool=generate_image, call_id), снимается по tool_end/artifact_created — реальная карточка встаёт на его место. Прогресс-бар — indeterminate (псевдозагрузка): реального прогресса генерация не отдаёт.
3 Caption — решение принято. Caption = prompt артефакта (content); отдельная человекочитаемая подпись от агента — возможное улучшение, backlog.
4 Стрим. Карточка приходит по SSE-событию до завершения ответа и выглядит идентично финальной — отдельного «streaming»-вида у карточки нет (так уже работает для текстовых артефактов: streamingArtifacts в MessageList). Пульсирующая точка в тексте — условность мокапа, а не элемент продукта. FeedbackButtons появляются только после завершения.
5 Состояния «Загрузка» и «Ошибка 404» — новые. В текущей заглушке вьюера их нет. Скелетон держит каркас (header, зум, caption на месте) и то же соотношение сторон. При отсутствии блоба — пустое состояние в стилистике текущей заглушки (иконка + mono-текст); зум-pill скрыт, скачивание выключено. Кнопка «.png» в состоянии «Готово» реально скачивает изображение.
