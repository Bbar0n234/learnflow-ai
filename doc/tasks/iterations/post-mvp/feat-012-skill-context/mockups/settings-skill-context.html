Аннотации к дизайну

1 Группировка по скиллу, документы внутри — отражает модель хранения: namespace ("user", uid, "skill_context", <skill>), ключи — документы. Клик по строке документа раскрывает отрендеренный Markdown-предпросмотр; длинный контент скроллится внутри превью.
2 Карандаш переключает превью в сырой Markdown (textarea) — «Сохранить» рендерит обратно, «Отмена» откатывает. Создание документов из UI не предусмотрено (создаёт агент); пользователю — просмотр, правка, удаление. Сохранение проходит security-checkpoint (инъекция → 422, сообщение как у «Своих инструкций»).
3 Данные переживают скилл. Скилл убрали из библиотеки — группа остаётся с бейджем «скилла нет в библиотеке»: данные не умирают молча, но агент их больше не получает (доставка привязана к load_skill). Удаление документа — мгновенное, с возможностью вернуть через агента (в мокапе просто удаляет строку).
