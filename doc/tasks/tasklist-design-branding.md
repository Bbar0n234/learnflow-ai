# Tasklist: Design-branding

## Контекст

Сквозной трек визуальной идентичности продукта: брендовый язык, иллюстрации,
прозрачные ассеты, бренд-кит и оформление репозитория/платформ. Идёт параллельно
продуктовым фазам, не привязан к одной из них. Питается из backlog (P2 Design
system) и собственных research-итераций.

Трек подготавливает ассеты и pipeline; интеграция в код фронтенда — отдельная
итерация трека, помеченная cross: frontend (арты доводятся здесь, применение в
UI согласуется с frontend-треком).

**Документы:** [roadmap.md](../product/roadmap.md) (секция «Сквозные треки»), итерации в `iterations/design-branding/`.

## Легенда

- 📋 Planned
- 🚧 In Progress
- ✅ Done
- ⏸️ Paused

## Зависимости

```
feat-001 (PoC) ──┬─ feat-002 (mass cutout) ── feat-003 (SVG) ──┐
                 │                                              ├─ feat-004 (доводка + интеграция)
                 └─ feat-005 (бренд-кит / репо) ────────────────┘
```

- **feat-002** опирается на найденный в PoC managed-подход; для batch-объёма желательна HF-подписка (см. backlog, Cross-cutting → «HF Pro utilization»).
- **feat-003** принимает на вход уже утверждённый прозрачный PNG (после feat-002).
- **feat-004** доводит арты и применяет утверждённые ассеты в UI.
- **feat-005** может идти параллельно (баннеры/логотипы/репо), переиспользуя стиль и cutout/SVG-pipeline.

**Цель:** концептуально проработать визуальную идентичность и доказать жизнеспособность pipeline — от стиля и генерации до прозрачных ассетов. Подготовительная итерация: генерация и обработка ассетов, без интеграции в код фронтенда.

**Статус:** ✅ Done
**Закрывает:** визуальную идентичность и первичные брендовые ассеты для экранов из frontend.md
**Ветка:** `feat/feat-007-design-branding` (историческое имя ветки; в треке — feat-001)

### feat-002: Массовое качественное вырезание фона

**Цель:** прогнать весь финальный пак (light + dark, потенциально до ~50 картинок при повторных генерациях) через managed BiRefNet General-HR, добить мелкие артефакты края лёгкой постобработкой и собрать единый production-пак прозрачных PNG взамен локального fallback.

**Статус:** 📋 Planned
**Blocked by:** feat-001
**Зависит от:** HF-подписки для batch-объёма (backlog, Cross-cutting)

#### Предварительный состав
- Прогон всех сцен через managed BiRefNet (HF Space / API при масштабе)
- Постобработка края (edge decontamination, добивание мелких артефактов)
- Единый прозрачный пак + обновление candidate-структуры
- Фиксация воспроизводимого batch-процесса

### feat-003: Векторизация в SVG

**Цель:** превратить утверждённый прозрачный пак в SVG для резкости на любых разрешениях. Open problem — подход и инструменты определяются на этапе планирования (research уже начат в feat-001).

**Статус:** 📋 Planned
**Blocked by:** feat-002 (вход — утверждённый прозрачный PNG, иначе дефекты маски станут лишними paths)

#### Предварительный состав
- Выбор и бенчмарк инструментов векторизации под наш плоский стиль
- Контроль качества (контуры, заливки, вес файла) на тёмном и светлом фоне
- Production SVG-пак

### feat-004: Художественная доводка + интеграция (cross: frontend)

**Цель:** довести арты по результатам живого просмотра (персонажи, акценты, метафоры — точечные правки там, где «человек посмотрел, тут не нравится») и интегрировать утверждённые токены и cutout/SVG в код фронтенда.

**Статус:** 📋 Planned
**Blocked by:** feat-002 (и feat-003, если интегрируем SVG)
**Cross:** frontend (применение в UI согласуется с frontend-треком)

#### Предварительный состав
- Ревизия финального пака на реальных экранах, список точечных правок
- Перегенерация/доводка отдельных сцен и персонажей
- Применение токенов light/dark и прозрачных ассетов в компонентах UI

---

### feat-005: Бренд-кит и оформление репозитория / платформ

**Цель:** расширить визуальную идентичность за пределы продуктового UI в полноценный бренд-кит и оформить точки присутствия проекта.

**Статус:** 📋 Planned
**Blocked by:** feat-001 (стиль), переиспользует cutout/SVG-pipeline

#### Предварительный состав
- Генерация баннеров, логотипов, фонов в едином стиле + их векторизация (полный кит)
- Оформление GitHub-репозитория: README, баннеры, splash-графика
- Кросс-платформенные ассеты (соцсети, лендинг и т.п.)
- Seed (низкий приоритет, опционально): видео-заставки, музыкальная айдентика
