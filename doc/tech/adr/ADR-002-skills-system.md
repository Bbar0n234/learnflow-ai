# ADR-002: Skills System

## Статус

Принято

## Контекст

General Agent ([ADR-001](ADR-001-general-agent.md)) нужен механизм расширения поведения. Новые навыки должны добавляться без изменения кода агента. Навыки — это экспертные знания: как структурировать материал, как искать информацию, какие паттерны использовать.

## Решение

Skills — подгружаемые модули, расширяющие поведение агента.

**Структура skill'а:**
- **Описание** — что делает
- **Паттерны** — когда использовать (триггеры)
- **Знания** — как делать (prompts, docs)

**MVP:** файловая система + API-обёртка для подгрузки.

**Lifecycle:**
1. Пользователь формулирует задачу
2. Агент подгружает релевантный skill в контекст (just-in-time)
3. Использует знания из skill'а
4. Skill выгружается из контекста
5. При необходимости — подгружается снова

**Планируемые skills:** structure, research, slides (v1.5), audience-adaptation.

## Почему Skills

- **Общепринятый стандарт**, набирающий обороты в индустрии
- **Расширяемость:** легко добавить свой skill без изменения кода агента
- **Переиспользуемость:** skills из проекта можно использовать отдельно (standalone-скиллы)
- **Контрибьюции:** сообщество может пополнять набор навыков

## Альтернативы

### Всё в одном промпте (отклонено)

Все знания и инструкции зашиты в system prompt агента.

**Причина отклонения:** не расширяемо — добавление навыка = переписывание промпта. Раздувает контекст: все знания загружены всегда, даже когда не нужны.

### Hardcoded tools без knowledge-слоя (отклонено)

Агент расширяется только через tools (конкретные действия: search, generate).

**Причина отклонения:** tools = действия (*что* вызвать), но не знания (*как* делать). Skill = знания (как структурировать доклад, какие паттерны применить) + опционально tools. Без knowledge-слоя агент может искать и генерировать, но не знает методик и подходов.

## Следствия

- Код агента меняется редко, поведение — через конфигурацию
- Skills — основной механизм расширения и персонализации
- Standalone-скиллы возможны как отдельный канал дистрибуции
- Just-in-time подгрузка экономит контекстное окно
