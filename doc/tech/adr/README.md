# Architecture Decision Records (ADR)

Здесь фиксируются ключевые архитектурные решения проекта.

## Формат ADR

Каждое решение оформляется как отдельный файл:
- `ADR-001-<название>.md`
- `ADR-002-<название>.md`
- ...
