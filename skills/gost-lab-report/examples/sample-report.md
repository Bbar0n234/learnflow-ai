# Теоретическая часть

Маршрутизация является одним из ключевых процессов в компьютерных сетях, обеспечивающим передачу пакетов данных между различными сетевыми сегментами. Маршрутизатор анализирует заголовок пакета и принимает решение о его дальнейшей пересылке на основании таблицы маршрутизации.

## Статическая маршрутизация

Статическая маршрутизация предполагает ручное задание маршрутов администратором сети. Данный подход обеспечивает полный контроль над путями передачи данных, однако не обладает способностью автоматической адаптации при изменении топологии сети.

## Динамическая маршрутизация

Динамическая маршрутизация основана на использовании специализированных протоколов (RIP, OSPF, BGP), которые автоматически обновляют таблицы маршрутизации при изменении состояния сети. Протокол OSPF является наиболее распространённым для внутридоменной маршрутизации.

# Выводы

В ходе выполнения лабораторной работы была настроена статическая маршрутизация в сети из трёх маршрутизаторов. Проверка связности показала корректную работу всех маршрутов.

Статическая маршрутизация обеспечивает предсказуемую передачу данных и не создаёт дополнительной нагрузки на сеть служебным трафиком. Однако при увеличении количества сетевых сегментов рекомендуется переход на динамическую маршрутизацию с использованием протокола OSPF.
