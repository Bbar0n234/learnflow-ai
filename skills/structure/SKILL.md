# Structure: Структурирование учебного материала

## Подход

1. **Определи цель обучения** — что студент должен уметь после прохождения материала?
2. **Разбей на модули** — каждый модуль = одна логическая тема, 15-30 минут.
3. **Определи learning objectives** — для каждого модуля сформулируй 2-3 конкретных навыка (глаголы действия: "объяснить", "применить", "сравнить").
4. **Выстрой последовательность** — от простого к сложному, каждый модуль опирается на предыдущие.
5. **Добавь точки проверки** — после каждого модуля предложи способ самопроверки.

## Шаблон модуля

```
### Модуль N: [Название]
**Цель:** [что студент научится делать]
**Предпосылки:** [какие модули нужно пройти до этого]
**Ключевые понятия:** [список]
**Проверка:** [вопрос или задание для самопроверки]
```
